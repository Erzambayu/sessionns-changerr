### Summary (up to 250 characters)


### Description (long form, supports basic HTML)
```
Session Switcher 2 lets you save the full session state of any website under a named profile, then switch between accounts on the same site without logging out and back in.

═══════════════════════════════
KEY FEATURES
═══════════════════════════════

🔐 Session Management
Save and switch between accounts with one click. Each session captures cookies, localStorage, sessionStorage, and IndexedDB metadata.

⚡ Quick Switcher (Ctrl+K)
Fuzzy search across every saved session on every site. Cross-domain switch automatically opens a new tab.

🔢 Badge Counter
The toolbar icon shows the number of saved sessions for the current domain at a glance.

⌨️ Keyboard-First
- Ctrl+K / Cmd+K — open quick switcher
- Ctrl+Shift+S / Cmd+Shift+S — open the popup
- / — focus search
- 1-9 — switch to the nth session
- Esc — close any modal

🔒 Local & Secure
All data stays on your device in browser local storage. No telemetry, no analytics, no remote sync, no accounts.

🔐 Optional PIN Protection
Gate switching, editing, exporting, and deleting behind a PIN. Hashed with PBKDF2 (SHA-256, 200,000 iterations, per-install salt). Never stored in plaintext.

📤 Export & Import
Backup as JSON or ZIP. Restore on another device or after reinstall.

🎨 Editorial Dark UI
Warm-dark theme, refined typography (Fraunces serif + JetBrains Mono + Inter), sharp amber accent. Designed for daily use.

♿ Accessible
Proper ARIA roles, focus traps, aria-live announcements, prefers-reduced-motion support.

═══════════════════════════════
USE CASES
═══════════════════════════════

• Personal Gmail vs work Gmail
• Multiple GitHub / Twitter / Discord accounts
• Web developers testing logged-in / logged-out / admin states
• Anyone managing multiple accounts they own

═══════════════════════════════
PRIVACY
═══════════════════════════════

Session Switcher 2 makes ZERO network requests. Your session data never leaves your device. The extension is open source and licensed under MIT — verify the claims yourself.

Privacy policy: https://github.com/Erzambayu/sessionns-changerr/blob/main/PRIVACY.md
Source code: https://github.com/Erzambayu/sessionns-changerr

═══════════════════════════════
PERMISSIONS
═══════════════════════════════

The extension requests <all_urls> because users save sessions on arbitrary sites of their choosing. On Firefox MV3, this is correctly treated as opt-in: the popup shows a banner asking for explicit permission only on first use.

═══════════════════════════════
RESPONSIBLE USE
═══════════════════════════════

This extension is for managing accounts you legitimately own. It is NOT for accessing other people's accounts, hijacking sessions, or any unauthorized activity. You are responsible for how you use it.

═══════════════════════════════
CREDITS
═══════════════════════════════

Original project: session-switcher2 by kuronekony4n
Maintained by: Erzambayu
Open source under MIT License
```

## Submission checklist

Before submitting to AMO:

- [ ] Sign up at https://addons.mozilla.org/developers/
- [ ] Verify email
- [ ] Click "Submit a New Add-on"
- [ ] Choose **"On this site"** (Listed) for public discovery, or **"On your own"** (Unlisted) for private use
- [ ] Upload `session-switcher2-v1.9.0-firefox.zip` (the runtime build, not the `.xpi`)
- [ ] When asked "Do you need to upload source code?": **YES**
  - Upload `session-switcher2-v1.9.0-amo-source.zip`
  - Reason: bundled output from TypeScript + esbuild (see AMO_BUILD_NOTES.md inside the source ZIP)
- [ ] Paste reviewer notes from `AMO_REVIEWER_NOTES.md`
- [ ] Fill listing fields from this document
- [ ] Add 1-3 screenshots (1280x800 recommended)
- [ ] Set privacy policy URL
- [ ] Set support email + homepage
- [ ] Submit and wait for review (typically 1-7 days for Listed; instant signing for Unlisted)

## Post-approval

Once approved:
- AMO publishes a signed `.xpi` accessible at `https://addons.mozilla.org/firefox/addon/session-switcher-2/` (or similar slug)
- Update README.md install instructions to point to AMO listing
- Update GitHub release notes to add AMO link
- Optionally remove the "Firefox Stable signing pending" caveat from the README

## Versioning notes

- Each new version requires a new submission and a new review.
- AMO automatically assigns increasing version numbers, so manifest version must always be greater than the last published version.
- Stay below 5 MB total size (we're at ~92 KB, plenty of headroom).
